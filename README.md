A large datapack that adds 20+ insects to your world! Exploration is highly incentivized, so get out there and catch all the bugs, see all the sights, and curate the perfect bug collection! 

# Contents

### **Features**
- **Bugcatching:** Bug Nets, Pollen, and more items create a rich critter-catching experience!
- **Terrariums:** A versatile block with endless customization for displaying and feeding insects.
- **Bubble Wand:** Blow bubbles that can be used for fun or to catch insects!

### **Extras**
- New Advancement Tab: **Entomology**
- Custom Statistics Tracking
- Addon Recipes for [Crop & Kettle](https://modrinth.com/datapack/crop-and-kettle)

### **Updates**
- Thorax will be ported to the most recent version of Minecraft frequently!
- New content such as New Insects, Biomes, and general improvements are in the works!
- Report bugs and give feedback on the Discord or Issue Tracker!
